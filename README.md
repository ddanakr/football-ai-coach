# Football AI Coach (P01)

Заглушка. Football AI Coach превращает запись матча КПЛ в каталог событий с таймкодами. Полное описание: `CLAUDE.md`, ТЗ: `docs/TZ.md`.

## Быстрый старт (Windows, PowerShell)

1. Создать окружение: `python -m venv .venv` и активировать `.venv\Scripts\Activate.ps1`.
2. Установить пакет с dev-зависимостями: `pip install -e ".[dev]"`.
3. Проверить качество: `python scripts/check.py` (ruff, ruff format, mypy, pytest).

> Хук `mypy` в `pre-commit` запускает `.venv\Scripts\python.exe`, поэтому окружение должно лежать именно в папке `.venv` в корне репозитория (Windows). Установка хуков: `pre-commit install` (ставит и хук проверки сообщения коммита).

## Метрики качества (`aicoach.eval`)

Модуль сопоставляет предсказания с эталоном и считает TP, FP, FN, precision, recall, медиану и 90-й процентиль ошибки таймкода (по классам и общие, micro) и 95% bootstrap-интервалы. Допуски по умолчанию 5 и 10 с считаются одним вызовом `evaluate(...)`; таблица в markdown: `format_markdown(report)`.

**Допуск `tolerance_s` это половина окна.** Событие найдено, если `|t_pred - t_gt| <= tolerance_s`, граница включена. В SoccerNet параметр δ означает ширину всего окна, поэтому `tolerance_s = δ / 2`: δ = 10 с в SoccerNet соответствует `tolerance_s = 5.0` здесь, а допуск «±5 с» из ТЗ это `tolerance_s = 5.0`. Сравнивая наши цифры с цифрами SoccerNet, сверяйте именно эту трактовку.

Правила сопоставления:

- Предсказание `goal` со `status = "disallowed"` считается ударом (`shot`).
- Сопоставление по классам, жадное: пары с `|dt| <= tolerance_s` сортируются по `|dt|` (при равенстве по индексам), эталон и предсказание участвуют максимум в одной паре.
- Если делить не на что (нет предсказаний или нет эталона), precision и recall равны `None`, а не 0.
- Bootstrap: 1000 ресэмплов с возвращением по флагам «найдено/верно», seed фиксирован; при пустых данных `None`. Для одного матча результат называется пилотом.
- Фильтр `half=1|2` отбрасывает события другого тайма. Предсказание без поля `half` относится к тайму по границам из файла эталона (`halves.start <= t_v <= halves.end`, границы включены) и передаётся как `evaluate(..., half=2, halves=gt.halves)`; вне границ предсказание исключается. Если границы запрошенного тайма не заданы, а такое предсказание есть, будет `EvalError`.

### Формат файла эталона

Файл читает `load_ground_truth` (`src/aicoach/eval/schemas.py`, описание полей в докстринге класса `GroundTruth`):

- `video` (строка, обязательно): имя размеченного видеофайла;
- `halves` (необязательно): ключи `"1"` и `"2"`, в каждом `{"start": число|null, "end": число|null}`, секунды от начала всего файла;
- `events` (список, обязательно): `type` (`goal|shot|corner|foul|subst`), `t_v` (секунды, конечное число, не меньше 0), `half` (1|2); необязательные `clock`, `team` (`home|away|null`), `visibility` (по умолчанию `true`), `replay` (по умолчанию `false`), `annotator`, `note`.

Напоминание: `tolerance_s` это половина окна (δ SoccerNet = 2 × `tolerance_s`).
